# 📚 Discord Study Tracker Bot

A Discord bot that automatically tracks study time using voice channels.

## ✨ Features

- 🎧 Automatic voice channel tracking
- 📊 `/stats` command
- ⏱️ Daily study time
- 📅 Weekly study time
- 🗓️ Monthly study time
- 🏆 Lifetime study time

## 🛠️ Tech Stack

- TypeScript
- Discord.js v14
- Node.js

## 🚀 Installation

```bash
npm install
npm run dev
```

## 📌 Commands

| Command | Description |
|---------|-------------|
| `/stats` | Shows your study statistics |
