
# Discord Study Tracker Bot

A Discord bot that automatically tracks study time through voice channels.

## Features

- 🎧 Automatic Voice Tracking
- 📊 Study Statistics
- 👤 User Profile
- 🏆 Leaderboard
- 🎯 Daily Goals
- 📅 Attendance Tracking
- 🔥 Study Streak
- 💾 SQLite Database

## Commands

- `/stats`
- `/profile`
- `/leaderboard`
- `/goal`
- `/mygoal`
- `/attendance`
- `/streak`

## Tech Stack

- TypeScript
- Node.js
- Discord.js
- SQLite
